# Melgram

Личный форк официального Telegram для Android (исходники: github.com/DrKLO/Telegram, версия 13.0.3).

Что изменено:
- до **6 аккаунтов** без Premium (число можно поменять при запуске сборки);
- название **Melgram** и свой пакет `com.melgram.app` — ставится рядом с обычным Telegram;
- своя иконка вместо логотипа Telegram и 8 встроенных иконок (меняют настоящий значок);
- **Настройки → Настройки Melgram** — всё на одном экране:
  - иконка приложения: встроенные картинки или своя из галереи (ярлыком на рабочем столе);
  - звук уведомления из любого аудио/видео до 5 минут: выделяешь фрагмент на волне, Melgram сжимает его в Ogg/Opus и загружает в Telegram (можно сразу во все аккаунты);
  - улучшения с кнопкой «Включить всё»: кнопка «Наверх» в списке чатов, скрыть истории, время с секундами, точные числа (34,355 вместо 34K), без перехода к следующему каналу, прятать клавиатуру при прокрутке, спрашивать перед звонком, без звука от незнакомых, без стикера-приветствия, без тени панели, без «жидкой» анимации аватара, без миниатюр в списке чатов, режим планшета;
  - фоновое соединение отдельно для каждого аккаунта (экономия батареи на второстепенных аккаунтах);
  - проверка обновлений (через GitHub API — новая сборка видна сразу).

Улучшения — «мягкие» правки: если новая версия Telegram ломает одну из них, Melgram собирается без неё, а в настройках она помечается как недоступная. Иконки пересобираются скриптом `melgram/make_icon_set.py` из картинок в `melgram/icons`.

## Как собрать (можно с телефона)

1. **Ключи.** Зайди на my.telegram.org → войди по номеру → *API development tools* → создай приложение (Title: Melgram, Short name: melgram, Platform: Android). Скопируй `api_id` и `api_hash`.
2. **Репозиторий.** На github.com нажми **+ → New repository**, имя `melgram`, тип **Public** (у публичных сборки бесплатные и на более мощных машинах; ключи всё равно хранятся в секретах и никому не видны).
3. **Файлы.** *Add file → Upload files* → загрузи `melgram.zip`.
   Если хочешь другую стандартную иконку, загрузи рядом картинку с именем `icon.jpg` или `icon.png`.
4. **Сценарий сборки.** *Add file → Create new file*, в имени файла напиши `.github/workflows/build.yml`, вставь содержимое `build.yml` и нажми *Commit changes*.
5. **Секреты.** *Settings → Secrets and variables → Actions → New repository secret*:
   - `API_ID` — число с my.telegram.org;
   - `API_HASH` — строка с my.telegram.org.
6. **Сборка.** Вкладка *Actions* → *Собрать Melgram* → *Run workflow*. Сборка идёт 1–2 часа.
7. **Скачать.** Готовый APK появится на главной странице репозитория справа в **Releases**.

## Если уведомления приходят с задержкой

Пуш-уведомления Google привязаны к официальному Telegram, поэтому в форке открой *Настройки → Уведомления*, пролистай в самый низ и включи оба пункта про фоновую работу (в английском интерфейсе — *Keep-Alive Service* и *Background Connection*).

## Автообновление

- Каждый день в 06:17 по Москве GitHub проверяет официальный Telegram. Если вышла новая версия, Melgram собирается сам и появляется в Releases.
- Melgram при запуске (не чаще раза в 6 часов) смотрит `update.json` и предлагает обновиться. Вручную: *Настройки → Обновления Melgram*.
- Если новая версия Telegram сломала правки Melgram, в `update.json` записывается `blocked`, а в приложении появляется сообщение «Обновление невозможно… напишите @miku_gf». Автосборка этой версии больше не повторяется, пока её не исправят.
- Пересобрать вручную: *Actions → Собрать Melgram → Run workflow* (версия Telegram «текущая» или «последняя»).
